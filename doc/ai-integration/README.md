# AI Agent Integration

## 1. Setup cream skill

Use `Setup cream skill` when setting cream.kt up. It sets cream.kt up in a Kotlin module right
away, taking care of the KSP setup and the workaround needed for KMP.

### Install

```shell
gh skill install TBSten/cream setup-cream
```

## 2. Refactor by cream skill

Searches your project's code for common refactorable patterns and refactors them.

### Install

```shell
gh skill install TBSten/cream refactor-by-cream
```
