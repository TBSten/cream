# AI Agent との統合

## 1. Setup cream skill

cream.kt をセットアップする際は `Setup cream skill` を利用してください。
KSP のセットアップや, KMP でのワークアラウンドを考慮して 今すぐ Kotlin のモジュールに cream.kt をセットアップします。

### Install

```shell
gh skill install TBSten/cream setup-cream
```

## 2. Refactor by cream skill

一般的なリファクタリング可能なパターンをプロジェクト内のコードから探してリファクタリングを行います。

### Install

```shell
gh skill install TBSten/cream refactor-by-cream
```
