# architecture-test

This katachi definition, the one test that checks the repository against it, and the pages it generates

cream のアーキテクチャ規約（置き場所・依存方向・命名・テスト / doc の規約）の SSoT。`./gradlew :architecture-test:test` が
リポジトリ全体をこの定義に照らして検査し、`./gradlew :architecture-test:katachiDocs` が同じ定義から `doc/internal/architecture/`
を再生成する。

| Role | Summary |
|---|---|
| [ArchitectureDefinition](./ArchitectureDefinition.md) | The `architecture { }` definition: one file per group (`<group>/<Group>.kt`) and per role (`<group>/<role>/<Role>.kt`) |
| [ArchitectureSpec](./ArchitectureSpec.md) | The single test calling `projectArchitecture.assert(FileConstraintCheck())` |
| [ArchitectureDocs](./ArchitectureDocs.md) | Pages generated by `katachiDocs` from this definition. Not written by hand |

## Placement in this group

```
architecture-test/src/test/kotlin/me/tbsten/cream/test/architecture/
  ProjectArchitecture.kt           ArchitectureDefinition
  */**/*.kt                        ArchitectureDefinition
  ProjectArchitectureTest.kt       ArchitectureSpec
doc/internal/architecture/**/*.md  ArchitectureDocs
```
